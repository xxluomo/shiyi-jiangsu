# 拾遗 · 江南非遗数字文化馆

课题名称：**基于Web的非遗数字文化展示与管理系统设计与实现**。

这是一个有真实前端、Python后端和SQLite数据库的本地网站。不是只有页面的静态模板；项目新增、编辑、删除、图片上传、答题评分与统计均通过HTTP接口和数据库完成。

## 1. 如何启动

1. 双击当前文件夹内的 **启动网站.bat**。
2. 保持弹出的命令行窗口打开，浏览器会自动打开首页。
3. 前台：http://127.0.0.1:8000
4. 后台：http://127.0.0.1:8000/admin
5. 关闭网站时，在命令行窗口按 `Ctrl+C`，或关闭该窗口。

**后台演示账号：**

| 项目 | 内容 |
| --- | --- |
| 账号 | `admin` |
| 密码 | `Heritage2026!` |

运行要求：Python 3.10或更高版本，Edge或Chrome浏览器。项目只使用Python标准库，不需要安装Flask、Django、Node.js、MySQL，也不需要执行pip安装。你的电脑已具备所需环境。

如双击启动异常，请在本文件夹打开终端，运行：

```powershell
python server.py --open
```

如果8000端口被其他程序占用，改用：

```powershell
python server.py --port 8001 --open
```

此时后台地址相应变为 `http://127.0.0.1:8001/admin`。请通过这个本地网址访问，不要直接双击HTML文件。

## 2. 已完成的功能

| 功能 | 操作 | 实现位置 |
| --- | --- | --- |
| 图文展馆 | 首页浏览4个非遗项目 | 前端排版＋后端查询数据库 |
| 分类筛选 | 全部馆藏、传统美术、传统技艺 | 后端按分类查询 |
| 关键词搜索 | 按标题、介绍或地域搜索 | 参数化SQL查询 |
| 项目详情 | 阅读文化故事、工艺概览、资料来源 | 详情接口＋弹窗 |

| 非遗答题 | 从6道题中抽5道、完整作答后提交 | 服务器随机抽题、评分、保存记录 |

| 管理员登录 | 账号密码验证、会话保持、退出 | 密码摘要＋数据库会话 |

默认馆藏：惠山泥人、宜兴紫砂陶制作技艺、无锡精微绣、无锡留青竹刻。

## 3. 建议的演示顺序（约5分钟）

1. 展示首页，介绍“以图文与互动传播江南非遗”的主题。
2. 切换“传统技艺”，看到紫砂项目；搜索“宜兴”，展示后端检索。
3. 打开项目详情，展示故事、步骤、来源，再点击配图放大。
4. 完成一次5题小测，展示得分和解析。
5. 进入后台，用演示账号登录，展示答题记录和统计。
6. 编辑一个项目的介绍并保存，返回前台刷新，证明前后端与数据库确实连接。
7. 展示新增项目、图片上传与删除确认界面。实际演示删除时，建议先新建一个“演示项目”，再删除它。

演示前备份一次 `data` 文件夹，可以避免误删原始内容。

## 5. 如何修改与保存

- 修改馆藏：登录后台，点击“编辑”或“新增项目”，填写文字后保存。
- 修改配图：可以选择自带插画，也可以上传有使用权限的图片。上传成功后还需点击“保存项目”。
- 工艺步骤：一行填写一项，最多10项，每项最多240字。
- 资料来源：必须填写有效的http或https网址及来源名称。
- 修改界面：用VS Code打开整个“大作业”文件夹，编辑static中的HTML、CSS、JS，浏览器刷新查看。后端代码修改后需重启服务。
- 修改题目：题库初始化位于seed.json；已经运行过的数据库不会被seed覆盖。如要更改现有题目，可使用SQLite工具或编写SQL更新questions表。当前版本没有题库管理页面。
- 数据持久化：项目内容和答题记录保存在SQLite文件中，关闭窗口或重新启动服务不会丢失。
- 备份迁移：先关闭服务，再完整复制“大作业”文件夹，或至少备份data文件夹。不要只复制数据库而漏掉uploads图片。

## 6. 运行边界

这是用于本机课程演示的系统，只监听127.0.0.1，不自动开放局域网或公网。固定账号用于本地演示。如以后上线，需要另行完成部署、HTTPS、账号维护及图片解码校验等工作。

首次初始化时可以通过环境变量 `HERITAGE_ADMIN_PASSWORD` 自定义初始密码；数据库已建立后更改这个变量不会覆盖原密码。

没有加入普通用户注册、评论、支付或视频上传，避免扩大课程项目范围。答题者不需要登录，系统只保存得分与时间，不收集身份。

上传功能检查文件头和大小；不承诺支持损坏图片。更换图片或删除馆藏后，旧文件暂时保留以避免误删共享文件，可在备份后人工清理。未保存的上传文件也会保留。
