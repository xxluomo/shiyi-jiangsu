# 拾遗江苏 · 非遗数字文化馆

课题：**基于Web的江苏非遗数字展示与互动学习平台设计与实现**。

![拾遗江苏首页](docs/screenshots-v2/01-home-desktop.png)

仓库保留项目代码、初始内容、媒体素材和文档；本机数据库、登录会话、用户作品与`.venv`环境不纳入版本管理。首次运行会自动初始化数据库及本地演示账号。

已在原“大作业”基础上完成核心升级：12项江苏非遗、6个城市、4个策展专题、2个Canvas互动工坊、4段约一分钟的本地中文音频、40题知识库，以及用户学习中心和策展后台。

## 一、启动和账号

1. 在资源管理器中**双击“启动网站.bat”**。单击只会选中文件并在预览窗中显示代码。
2. 浏览器会打开 **http://127.0.0.1:8000**。
3. 后台入口：**http://127.0.0.1:8000/#admin**。若提示需要管理员权限，点击“切换管理员登录”，再以admin / 123456登录。
4. 保持启动窗口打开；停止时按Ctrl+C，或双击“停止网站.bat”。

| 用途 | 账号 | 密码 |
| --- | --- | --- |
| 普通用户演示 | student | 123456 |

## 二、网页怎么用

### 首页与非遗展厅

首页展示精选项目、四个专题和实际馆藏数量。进入“非遗展厅”，可以按城市、非遗类别、策展专题筛选，也能搜索项目名称、材料或标签。四个专题是网站的编辑组织方式，不等同于官方非遗类别。

点击卡片进入详情：

- 点击缩略图切换整体与局部配图。
- 点击大图放大，通过滑块缩放，并拖动观察细节。
- 点击收藏按钮，保存至个人中心。
- 阅读背景介绍、资料来源及教学性工艺概览。
- 点击“了解工艺”，切换步骤或点击“下一步”；登录后保存进度。

正式精选内容为：南京云锦、南京剪纸、苏绣、昆曲、惠山泥人、宜兴紫砂陶、无锡精微绣、留青竹刻、扬州雕版印刷、扬州漆器、南通蓝印花布、徐州香包。

原数据库中另有一条用户测试项目“11”，升级时保留为后台草稿，未删除。管理员可在馆藏管理中编辑、发布或删除。

### 地图与图谱

- 地域地图：点击城市，右侧显示本馆收录的项目。灰色城市表示本期尚未收录，不表示当地没有非遗。
- 关联图谱：可切换按“专题／非遗类别／城市”组织，点击项目节点进入详情。手机可横向滑动图谱。
- 图谱根据数据库内容生成；关系表示策展归属，不冒充历史师承或AI语义推断。

### 数字工坊

**剪纸工坊：** 选择4/6/8向对称、基础图案和纸色，拖动画布绘制镂空线条。支持撤销上一笔、重做和重置。线宽作用于当前画面中的切线，最多保留100笔，每笔最多400点。

**蓝印纹样工坊：** 选择花卉、枝叶或几何纹样，调整大小、间距、旋转角度，并切换蓝底白花／白底蓝花。

**保存与导出：**

1. 输入作品名称。
2. 登录后点击“保存到我的作品”，服务端压缩作品并生成缩略图，记录写入数据库。
3. 点击“导出PNG图片”，等待生成下载链接，再点击“下载作品”。导出文件是720×720像素的PNG。
4. 个人中心可以查看、下载或删除自己保存的作品。其他普通用户不能读取或删除你的作品记录。

数字工坊是创意与构图体验，不代替真实手工制作教程。

### 视听与学习

- 选择4段文化导览之一，点击播放器播放，支持暂停和进度拖动。
- 展开文字稿可以同步阅读。
- 导览使用Microsoft Huihui中文离线合成语音，不是传承人原声或现场录音。
- 知识挑战可选择5题或10题，由后端随机抽题。
- 点击选项作答，支持返回上一题或点击题号检查，完成全部题目后提交。
- 后端评分并显示逐题解析。登录后开始的答题会保存到个人中心；访客答题不关联个人。

### 个人中心

右上角点击昵称，可查看：我的收藏、我的作品、答题与错题、工艺学习进度。数据保存在SQLite中，刷新、关闭浏览器或重新启动网站后仍保留。

### 策展后台

使用admin账号登录，从页脚或个人中心进入“策展后台”。普通用户不能使用管理接口。

- 数据概览：馆藏数、用户数、作品数、答题数、平均分、城市分布条形图、类别环形图和最近答题。
- 馆藏管理：新增、编辑、删除、草稿／发布；维护城市、类别、专题、标签、来源和多图。
- 图片上传：8MB内的PNG、JPEG、WebP、GIF，实际解码后保存为WebP，并生成缩略图；不会只检查后缀名。
- 题库管理：新增、编辑、删除题目、四个选项、正确答案和解析。
- 导览管理：编辑讲稿并上传对应WAV。修改讲稿却未更换音频时，旧音频暂停展示，防止文稿与声音不一致。

已开始的答题使用题目快照，管理员修改或删除题目不会改变这次答题的正确答案和历史记录。

## 三、技术与目录

前端：HTML5、CSS响应式布局、原生JavaScript ES Modules、Canvas 2D、SVG地图与图谱、HTML5 Audio。

后端：Python HTTP服务＋SQLite＋Pillow。接口具有用户认证、角色权限、CSRF校验、输入验证和媒体解码校验。密码用带盐PBKDF2摘要保存，不以明文存入数据库。

## 四、维护与复现

本机已安装环境，平时只需双击bat。换电脑时，虚拟环境需要重建：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe start_local.py
```

运行自动化测试：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

测试使用独立临时数据库，不修改实际数据。数据迁移会保留原馆藏、历史答题和用户测试项目；初始内容只导入一次，之后编辑JSON不会覆盖后台修改。

先停止服务，再备份data文件夹。作品与上传图不能只备份数据库，还要保留uploads。导出的PNG也存于uploads，可在停止服务、确认不再需要后人工清理。当前版本没有自动清理导出文件的计划任务。

修改Python后端后需要重启服务；修改前端后刷新浏览器。升级前完整备份ZIP位于上一级“数字媒体技术前沿”目录，不会覆盖。

## 五、来源、边界和提交

主视觉为内置ImageGen生成的创意示意，项目配图为代码绘制SVG，均非真实馆藏或实拍。详见docs/视觉素材说明.md（含提示词和保存路径）。介绍与题库根据官方资料整理，来源见“内容来源说明.md”和每项详情。

江苏行政区数据来自已下载参考仓库的公开资源，仅用于课程地域探索示意。GitHub参考项目的功能与设计借鉴见docs/技术设计说明.md；核心交互和本地业务代码位于本项目，不依赖外部AI接口或在线图表CDN。

核心网站只监听127.0.0.1，未发布公网。完整3D漫游、AI问答／生成、票务支付没有加入；它们在docs/后续拓展清单.md中单独记录。
